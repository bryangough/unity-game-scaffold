# __GAME__: name candidates

The store title is decided once and is expensive to change (the app id, the save folder and the store pages hang
on it: the duel game renamed itself before launch and kept the old id). Brainstorm here, then check each finalist
and write the result in the table before the task list's naming task is ticked.

## What the name should do

1. Say the hook in two or three words (what the player does, or how it feels).
2. Pair with a plain subtitle for store search (`<Name>: <what kind of game>`).
3. Be ownable: no other game, trademark or well-known feature with the same name.
